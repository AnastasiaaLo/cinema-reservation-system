Sistem de Rezervare Cinema

Proiect C++ realizat în cadrul practicii de specialitate

Descrierea proiectului

Aplicația simulează un sistem simplu de rezervare a locurilor la cinema. Utilizatorul poate vedea filmele disponibile, poate alege o sală, poate rezerva locuri și poate anula rezervările efectuate.

Funcționalități

  • Afișarea filmelor disponibile
  • Afișarea sălilor disponibile
  • Rezervarea locurilor
  • Verificarea locurilor ocupate
  • Calcularea prețului total
  • Vizualizarea rezervărilor
  • Anularea rezervărilor

Tehnologii utilizate

  • C++
  • Dev-C++
  • GitHub
  • Trello
  • Markdown pentru documentație
